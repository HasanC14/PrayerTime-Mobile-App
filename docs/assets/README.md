# README visuals

These files are kept in Git so the root README can display them without depending on local marketing exports or remote image hosts. Documentation is excluded from native EAS build archives by `.easignore`.

- `banner.png`: the project's 1024 × 500 feature graphic.
- `prayer-times.png`, `prayer-journal.png`, `widgets.png`: selected 1080 × 1920 promotional screenshots from the 16 November 2026 asset pack. They show illustrative app data; countdowns and dates are not live.
- `google-play-badge.png`: the unmodified [official English Google Play badge](https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png), linked to `com.hasanbuilds.prayertime` in the root README. Preserve its proportions and built-in clear space.
